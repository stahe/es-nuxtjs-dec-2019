    15. Ejemplo [nuxt-12]: Solicitudes HTTP con axios

    15.1. Introducción

    En este nuevo ejemplo, veremos cómo realizar solicitudes HTTP utilizando la biblioteca [axios] dentro de funciones [asyncData]. Además, aplicaremos conceptos ya tratados:

    • el uso de plugins del ejemplo [nuxt-06]:
    • el almacenamiento del store en una cookie de sesión del ejemplo [nuxt-06];
    • el control de la navegación mediante middleware del ejemplo [nuxt-09];
    • el manejo de errores del ejemplo [nuxt-11];

    La arquitectura del ejemplo será la siguiente:

    • La aplicación [nuxt] se alojará en el servidor [node.js] [3], se descargará mediante el navegador [1], que luego la ejecutará;
    • tanto el cliente [nuxt] [1] como el servidor [nuxt] [3] realizarán solicitudes HTTP al servidor de datos [2]. Este servidor será el servidor de cálculo de impuestos desarrollado en la sección de PHP 7. Utilizaremos su última versión, la 14, con las solicitudes CORS habilitadas;

    La arquitectura del ejemplo se puede simplificar de la siguiente manera:

    • En [1], el servidor [node.js] envía las páginas [nuxt] al navegador [2]. Es la capa [web] [8] del servidor la que envía estas páginas. Para enviar la página, es posible que el servidor haya solicitado datos externos al servidor de datos [3]. Es la capa [DAO] [9] la que realiza las solicitudes HTTP necesarias;
    • Con cada solicitud de página al servidor [Node.js] [1], el navegador [2] recibe toda la aplicación [Nuxt], que luego se ejecuta en modo SPA. El bloque [UI] (interfaz de usuario) [4] muestra las páginas [Vue.js] al usuario. Las acciones del usuario o el ciclo de vida natural de las páginas pueden desencadenar solicitudes de datos externos al servidor de datos [3]. A continuación, la capa [DAO] [5] realiza las solicitudes HTTP necesarias;

    15.5.1. La capa [DAO] del servidor [Nuxt]

    El servidor [node.js] [1] utilizará la capa [DAO] descrita en el documento |Introducción al marco VUE.JS a través de ejemplos|. Aquí está el código de nuevo:

    
'use strict';
 
// imports
import qs from 'qs'
 
class Dao {
 
  // manufacturer
  constructor(axios) {
    this.axios = axios;
    // session cookie
    this.sessionCookieName = "PHPSESSID";
    this.sessionCookie = '';
  }
 
  // init session
  async  initSession() {
    // query options HHTP [get /main.php?action=init-session&type=json]
    const options = {
      method: "GET",
      // URL parameters
      params: {
        action: 'init-session',
        type: 'json'
      }
    };
    // execute query HTTP
    return await this.getRemoteData(options);
  }
 
  async  authentifierUtilisateur(user, password) {
    // query options HHTP [post /main.php?action=authenticate-user]
    const options = {
      method: "POST",
      headers: {
        'Content-type': 'application/x-www-form-urlencoded',
      },
      // body of POST
      data: qs.stringify({
        user: user,
        password: password
      }),
      // URL parameters
      params: {
        action: 'authentifier-utilisateur'
      }
    };
    // execute query HTTP
    return await this.getRemoteData(options);
  }
 
  async getAdminData() {
    // query options HHTP [get /main.php?action=get-admindata]
    const options = {
      method: "GET",
      // URL parameters
      params: {
        action: 'get-admindata'
      }
    };
    // execute query HTTP
    const data = await this.getRemoteData(options);
    // result
    return data;
  }
 
  async  getRemoteData(options) {
    // for the session cookie
    if (!options.headers) {
      options.headers = {};
    }
    options.headers.Cookie = this.sessionCookie;
    // execute query HTTP
    let response;
    try {
      // asynchronous request
      response = await this.axios.request('main.php', options);
    } catch (error) {
      // the [error] parameter is an exception instance - it can take various forms
      if (error.response) {
        // the server response is in [error.response]
        response = error.response;
      } else {
        // error restart
        throw error;
      }
    }
    // response is the entire HTTP response from the server (HTTP headers + response itself)
    // retrieve the session cookie if it exists
    const setCookie = response.headers['set-cookie'];
    if (setCookie) {
      // setCookie is an array
      // look for the session cookie in this table
      let trouvé = false;
      let i = 0;
      while (!trouvé && i < setCookie.length) {
        // look for the session cookie
        const results = RegExp('^(' + this.sessionCookieName + '.+?);').exec(setCookie[i]);
        if (results) {
          // the session cookie is stored
          // eslint-disable-next-line require-atomic-updates
          this.sessionCookie = results[1];
          // we found
          trouvé = true;
        } else {
          // next item
          i++;
        }
      }
    }
    // the server response is in [response.data]
    return response.data;
  }
}
 
// class export
export default Dao;

    En cuanto a la cookie de sesión, debemos tener en cuenta dos capas [dao] distintas:

    • la capa del navegador;
    • la capa del servidor;

    Tendremos que gestionar tres cookies de sesión:

    1. la que se intercambia entre el cliente [nuxt] y el servidor PHP 7;
    2. la que se intercambia entre el servidor [nuxt] y el servidor PHP 7;
    3. la que se intercambia entre el cliente [nuxt] y el servidor [nuxt];

    Nos aseguraremos de que la cookie de sesión con el servidor PHP sea la misma tanto para el cliente como para el servidor [nuxt]. Llamaremos a esta cookie la cookie de sesión PHP. Esta cookie es la de los casos 1 y 2. Llamaremos a la cookie del caso 3 la cookie de sesión [nuxt]. Por lo tanto, tendremos dos sesiones:

    • una sesión PHP con la cookie de sesión PHP;
    • una sesión [nuxt] con la cookie de sesión [nuxt];

    ¿Por qué utilizar la misma cookie para las sesiones PHP del cliente y las sesiones del navegador [nuxt]? Queremos que la aplicación pueda comunicarse con el servidor PHP 7 independientemente de si se trata del cliente o del servidor [nuxt]:

    • si una acción A del servidor [nuxt] pone al servidor PHP en el estado E, este estado se refleja en la sesión PHP mantenida por el servidor PHP;
    • al utilizar la misma cookie de sesión PHP que el servidor, una acción B del cliente [nuxt] que siga a la acción A del servidor [nuxt] encontraría al servidor PHP en el estado E dejado por el servidor [nuxt] y, por lo tanto, podría aprovechar el trabajo ya realizado por el servidor [nuxt];
    • si, tras la acción B del cliente [nuxt], le sigue una acción C del servidor [nuxt], por la misma razón que antes, esta acción podrá basarse en el trabajo realizado por la acción B del cliente [nuxt];

    Para permitir que el navegador del cliente [nuxt] se comunique con el servidor PHP de cálculo de impuestos, utilizaremos la versión 14 de este servidor, que permite llamadas entre dominios, es decir, llamadas desde un navegador al servidor PHP. Las llamadas del servidor [nuxt] al servidor PHP, sin embargo, no son llamadas entre dominios. Este concepto se aplica únicamente a las llamadas realizadas desde un navegador.

    La gestión de la cookie de sesión PHP anterior no es adecuada para el servidor [nuxt]: su capa [dao] se instancia con cada nueva solicitud realizada al servidor [nuxt]. Recordemos que solicitar una página al servidor [nuxt] reinicia efectivamente la aplicación [nuxt]. Por lo tanto, cuando el servidor [nuxt] realiza su primera solicitud al servidor de datos, se inicializa la cookie de sesión PHP para la capa [dao]; este valor se pierde durante la siguiente solicitud HTTP desde el mismo servidor [nuxt], ya que, entretanto, su capa [dao] se ha recreado, el constructor se ha vuelto a ejecutar y la cookie de sesión PHP se ha restablecido a una cadena vacía (línea 6);

    Una solución consiste en utilizar un constructor diferente para la capa [dao] del servidor:

    
// constructeur
  constructor(axios, phpSessionCookie) {
    // bibliothèque axios
    this.axios = axios
    // valeur du cookie de session
    this.phpSessionCookie = phpSessionCookie
    // nom du cookie de session du serveur PHP
    this.phpSessionCookieName = 'PHPSESSID'
  }
    • línea 2: en esta ocasión, la cookie de sesión de PHP se proporcionará al constructor de la capa [DAO] del servidor de datos;

    ¿Cómo proporcionará el servidor [nuxt] esta cookie de sesión de PHP al constructor de su capa [dao]? Almacenaremos la cookie de sesión de PHP en la cookie de sesión de [nuxt] intercambiada entre el navegador y el servidor [nuxt]. El proceso es el siguiente:

    1. Se inicia la aplicación [nuxt];
    2. cuando el servidor [nuxt] realiza su primera solicitud HTTP al servidor PHP, almacena la cookie de sesión PHP que ha recibido en la cookie de sesión [nuxt] que intercambia con el cliente [nuxt];
    3. El navegador que aloja el cliente [nuxt] recibe esta cookie de sesión [nuxt] y, por lo tanto, la reenvía automáticamente con cada nueva solicitud al servidor [nuxt];
    4. cuando el servidor [nuxt] necesita realizar una nueva solicitud al servidor PHP, encontrará la cookie de sesión PHP dentro de la cookie de sesión [nuxt] que le ha enviado el navegador. A continuación, la enviará al servidor PHP;

    De hecho, hay dos cookies de sesión, y no deben confundirse:

    • la cookie de sesión [nuxt] intercambiada entre el servidor [nuxt] y el navegador del cliente [nuxt];
    • la cookie de sesión PHP intercambiada entre el servidor [nuxt] y el servidor PHP o entre el cliente [nuxt] y el servidor PHP;

      let trouvé = false;

      while (!trouvé && i < setCookie.length) {

          // the session cookie is stored
          // eslint-disable-next-line require-atomic-updates
          this.sessionCookie = results[1];
          // we found
          trouvé = true;
        } else {
          // next item
          i++;
        }
      }
    }
    // the server response is in [response.data]
    return response.data;
  }

      • cuando se ejecuta el método [finSession] (el servidor PHP cambia la cookie de sesión de PHP);

    2. utilizando el método [getRemoteData] del servidor, que sabe cómo recuperar la nueva cookie de sesión de PHP;
